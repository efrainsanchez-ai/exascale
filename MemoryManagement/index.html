Overview

This workbook separates CDB Resource Manager capacity controls from database memory controls. Its recommendations are based on the measured host and database values in the review cards.

Review operating-system memory

On the observed VM, 25 GiB used of 32 GiB is about 78%, but Linux used memory includes reclaimable cache. Use `available` as the immediate headroom indicator.

Bash
Objective: Display physical memory, cache, swap, and available memory.
free -h
Output
Objective: Interpret the observed host-memory sample.
              total        used        free      shared  buff/cache   available
Mem:           32Gi        25Gi       1.2Gi       592Mi       5.7Gi       5.4Gi
Swap:          15Gi       152Mi        15Gi

The 5.4 GiB available value is below the 6 GB provisional root/background plus OS/transient envelope. Collect a workload time series before increasing database memory limits.

Review root CDB configuration

SQL
Objective: Confirm root memory parameters and whether they are defaults or explicit values on each RAC instance.
SET LINESIZE 220
SET PAGESIZE 100
SET TRIMSPOOL ON
SET TAB OFF

SELECT inst_id, name, value, isdefault, ismodified
FROM gv$parameter
WHERE name IN ('memory_target','memory_max_target','sga_target','sga_max_size',
               'pga_aggregate_target','pga_aggregate_limit')
ORDER BY inst_id, name;

Objective: Capture current SGA components and automatic-sizing ranges.

SET PAGESIZE 100
SET TRIMSPOOL ON
SET TAB OFF
SELECT inst_id, name, ROUND(value/1024/1024) AS sga_mb
FROM gv$sga ORDER BY inst_id, name;

SELECT inst_id, component,
       ROUND(current_size/1024/1024) AS current_mb,
       ROUND(min_size/1024/1024) AS min_mb,
       ROUND(max_size/1024/1024) AS max_mb,
       ROUND(user_specified_size/1024/1024) AS user_mb
FROM gv$sga_dynamic_components
WHERE current_size > 0
ORDER BY inst_id, component;

12-PDB memory implementation

Per-VM consumerAllowanceMeaning
PDB SGA targets18 GBPlatinum 8 GB, Gold 6 GB, Silver 4 GB.
PDB PGA limits9 GBHard PDB private-memory ceilings.
Root/backgroundUp to 3 GBProvisional, measured allowance.
OS/transient3 GBProtects host activity and short-lived demand.
SQL
Objective: Display all PDB SGA and PGA values before applying the tier model.
SET LINESIZE 220
SET PAGESIZE 100
SET TRIMSPOOL ON
SET TAB OFF

COLUMN pdb_name FORMAT A14
COLUMN name FORMAT A24
COLUMN value FORMAT A18

SELECT c.name AS pdb_name, p.name, p.value
FROM   cdb_parameters p
JOIN   v$containers c ON c.con_id = p.con_id
WHERE  p.name IN ('sga_target','pga_aggregate_target','pga_aggregate_limit')
ORDER BY p.con_id, p.name;

SQL
Objective: Display the PGA configuration for every user PDB in one table, ordered by PDB name.
SET LINESIZE 220
SET PAGESIZE 100
SET TRIMSPOOL ON
SET TAB OFF

COLUMN pdb_name FORMAT A14 HEADING 'PDB_NAME'
COLUMN pga_target FORMAT A18 HEADING 'PGA_TARGET'
COLUMN pga_limit FORMAT A18 HEADING 'PGA_LIMIT'

SELECT c.name AS pdb_name,
       MAX(CASE WHEN p.name = 'pga_aggregate_target' THEN p.value END) AS pga_target,
       MAX(CASE WHEN p.name = 'pga_aggregate_limit'  THEN p.value END) AS pga_limit
FROM   cdb_parameters p
JOIN   v$containers c ON c.con_id = p.con_id
WHERE  p.name IN ('pga_aggregate_target','pga_aggregate_limit')
AND    c.con_id > 2
GROUP BY c.name
ORDER BY pdb_name;
Output

-------------- ------------------ ------------------

...             ...                ...

Root SGA planning and adjustment

A 21 GB candidate root `SGA_TARGET` represents the 18 GB PDB SGA model plus up to 3 GB provisional root/background SGA allowance. It is a review-first candidate. Reduce PDB SGA targets if peak PGA or OS pressure makes it unsafe.

Warning: confirm `MEMORY_TARGET=0`, sufficient `SGA_MAX_SIZE`, and measured per-instance headroom before applying this change.
SQL
Objective: Show the current root memory values and whether Oracle reports each one as a default.
SET LINESIZE 220
SET PAGESIZE 100
SET TRIMSPOOL ON
SET TAB OFF

ALTER SESSION SET CONTAINER = CDB$ROOT;

COLUMN inst_id FORMAT 999 HEADING 'INST'
COLUMN name FORMAT A24
COLUMN value FORMAT A18
COLUMN isdefault FORMAT A10
COLUMN ismodified FORMAT A12

SELECT inst_id, name, value, isdefault, ismodified
FROM   gv$parameter
WHERE  name IN ('memory_target','memory_max_target','sga_target','sga_max_size',
                'pga_aggregate_target','pga_aggregate_limit')
ORDER BY inst_id, name;

Bash
Objective: Create the backup directory and save timestamped SPFILE and PFILE copies.
wb07_card01() {
  if [[ -z "${ORACLE_SID:-}" ]]; then
    clear
    printf 'STOP: Set ORACLE_SID for the target database before creating backups.\n'
    return 1
  fi

  local backup_dir="$HOME/backup"
  local backup_stamp
  backup_stamp="$(date +%Y%m%d_%H%M%S)"
  mkdir -p "$backup_dir" || return 1

  local spfile_backup="$backup_dir/spfile_${ORACLE_SID}_${backup_stamp}.ora"
  local pfile_backup="$backup_dir/init${ORACLE_SID}_${backup_stamp}.ora"

  sqlplus -s / as sysdba <<SQL
WHENEVER SQLERROR EXIT SQL.SQLCODE
CREATE SPFILE='${spfile_backup}' FROM SPFILE;
CREATE PFILE='${pfile_backup}' FROM SPFILE;
EXIT
SQL

  clear
  printf '%-14s | %s\n' 'ARTIFACT' 'PATH' \
    'SPFILE backup' "$spfile_backup" \
    'PFILE backup' "$pfile_backup"
  printf '\n%s\n' 'wb07_card01'
}
wb07_card01
Output
Objective: Confirm the generated backup paths.

Objective: Apply the reviewed root SGA candidate after approval.

ALTER SYSTEM SET SGA_TARGET = 21G SCOPE=BOTH;
